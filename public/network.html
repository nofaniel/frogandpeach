🌊 About tide predictions

Tide times are calculated locally using harmonic analysis — no internet, no API key, no sign-up required. The algorithm uses the published tidal constituents for Newquay Harbour (MHWS 5.1 m · MLWS 0.6 m).

Accuracy is typically ±20–30 minutes of the actual tide time. Always check official sources before sailing or cliff-base activities.
