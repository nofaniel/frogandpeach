Principles

Built the right way
for a household.

🔒

Private by default

Role-based login with timed admin unlock. Nothing is public unless you choose it. No third-party analytics or tracking.

🎨

Deeply customisable

Multiple themes, per-module settings, configurable display modes, and a full admin panel for the household manager.

☁️

Free to host

Runs entirely on the Cloudflare Pages free tier. No monthly bills, no servers to maintain, globally fast by default.

🛠

Developer friendly

TypeScript throughout. A built-in module registry makes it easy to add new household features with confidence.

Get started

Up and running
in minutes.

Deploy your own instance on Cloudflare Pages in a few commands. The free tier handles everything.

1

Clone and install. Run npm install and generate your admin password hash.

2

Apply local migrations. Run the D1 migration script to prepare local SQLite state.

3

Configure your location. Set your weather and tide location in the admin settings.

4

Deploy to Cloudflare. Run npm run cf:deploy or use your linked Pages Git deploy flow.

Quick start 
# Clone and install
git clone https://github.com/nofaniel/frogandpeach
cd frogandpeach
npm install

# Generate your admin password hash
npm run hash-password -- "your-password"

# Apply local D1 migrations
npm run cf:migrate:local

# Build and run locally
npm run build
npm run dev:worker

# Open http://localhost:8788
