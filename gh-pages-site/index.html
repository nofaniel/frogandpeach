Product stance

Private first, practical always.

01

No analytics or tracking

This is a household tool, not a product. No visitor funnels, no ad pixels, no telemetry. The data stays on your Cloudflare account.

02

Admin actions need a fresh unlock

Regular sessions and admin access are separate things. Sensitive changes require a timed re-authentication — no cached admin privileges hanging around.

03

Themes are data, not scripts

JSON themes map tokens to CSS custom properties. A snapshot in localStorage prevents the flash of unstyled content before React loads.

04

Runs on the free tier

Cloudflare Pages Functions and D1 keep hosting cheap. No servers to manage, no database to babysit, no surprise bills at the end of the month.

Run it locally

Clone, configure, migrate, run.

1

Install dependencies and generate a PBKDF2 password hash for the admin account.

2

Copy .env.example to .dev.vars and set the local app origin.

3

Apply D1 migrations, then start the full worker runtime.

PowerShell quick start
# Clone and install
git clone https://github.com/nofaniel/frogandpeach
cd frogandpeach
npm install

# Create your admin password hash
npm run hash-password -- "your-admin-password"

# Prepare local D1 and run the worker
npm run cf:migrate:local
npm run build
npm run dev:worker
